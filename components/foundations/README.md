# Foundations

**Status: normative.**

The core design decisions everything else inherits. Each is captured as design tokens
(named values) plus a short rationale, so they can be applied consistently by a person,
by an AI agent, and in code.

Files, added as we decide them:

- `typography.md`
- `shape.md`
- `spacing.md`
- `elevation.md`
- `iconography.md`
- `motion.md`
